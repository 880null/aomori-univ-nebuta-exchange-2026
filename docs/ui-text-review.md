# UI文言 翻訳確認シート

生成元: `lib/ui-text.ts`（37項目 × 6言語）

## このシートについて

アプリ画面のボタン・見出し・案内文の文言です。**ねぶたの解説本文はここには含まれません。**
解説本文・作品名・団体名・ねぶた師名・タグの値は青森観光コンベンション協会から提供された
確定テキストであり、翻訳も書き換えも行いません。確認していただくのはこのシートの範囲だけです。

## 確認のしかた

1. ご自分の担当言語の節だけを見てください。他の言語は見なくて構いません。
2. 各行の**日本語原文**と**現在の訳**を見比べ、`判定` 欄に次のいずれかを書いてください。
   - `OK` … このままでよい
   - `要修正` … 直したほうがよい（`修正案` 欄に直した文を書いてください）
   - `？` … 判断がつかない・原文の意味が分からない（`修正案` 欄に疑問点を書いてください）
3. `表示場所` は、その文言がアプリのどの画面に出るかです。訳の長さや語調を決める手がかりにしてください。

### 判断の基準

- **短さを優先してください。** スマートフォンの小さな画面に置くボタンや見出しです。
  意味が同じなら短いほうがよい訳です。
- **祭りの会場で、初めてこのアプリを開いた人が読みます。** 説明的すぎる訳より、
  一目で何のことか分かる訳を選んでください。
- **`{n}` `{total}` `{tag}` は消さないでください。** ここには数字や
  タグ名が自動で入ります。位置は各言語の語順に合わせて動かして構いませんが、
  括弧の中の綴りは1文字も変えないでください。
- **「読み上げ用」と書かれた行は画面に表示されません。** 目の見えない方が使う
  読み上げソフトが読む文です。画面に出る文言より少し説明的で構いません。

### 「原画」についての注記

権利者（青森観光コンベンション協会）から、**日本語では「下絵」ではなく「原画」と書くこと**
という指定を受けています。この指定がかかるのは**日本語の表記だけ**です。
やさしい日本語も日本語なので「原画」を使ってください。

**英語・中国語・韓国語では、担当言語として自然な語に訳してください。**
日本語の指定に引きずられて「原画」という字面をそのまま残す必要はありません。
選んでいただきたいのは、次の意味に合う語です。

- ねぶたを**作る前**に描かれる、完成の姿を示した絵
- 「複製に対する原本」という意味ではありません
- 落書きや下描きのような、粗い試し描きでもありません。仕上げられた1枚の絵です

現在の訳は次のとおりです。この意味に合っているか確認してください。

| 简体中文 | 原画 | No. 3 / No. 22 |
| 繁體中文 | 原畫 | No. 3 / No. 22 |
| 한국어 | 원화 | No. 3 / No. 22 |

この2項目で**同じ語**を使ってください（片方だけ変えると表記が割れます）。
