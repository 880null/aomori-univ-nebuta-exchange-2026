# docs

一次資料の置き場。**ここに置いたファイルは公開されない。**
GitHub Pages が配信するのは `npm run build` が生成する `out/` だけで、
`out/` に入るのは `app/` の出力と `public/` の中身に限られる。

## R8RasseLandMap.pdf

青森観光コンベンション協会「青森ねぶたラッセランド ねぶた制作小屋配置図」
（AOMORI NEBUTA FESTIVAL 2026）。

このアプリの**小屋番号（1〜23）の唯一の正**。`data/nebuta-source.csv` の
`Column 1` はこのPDFの番号に合わせてあり、一覧・詳細の「前へ／次へ」・
地図画面のリストはすべてこの番号順に並ぶ。

`lib/rasseland.ts` の相対座標も、このPDF右下の模式図を目視で採寸したもの。
**PDFに緯度経度の記載はない**ため、`rassetLandCenter` は依然として暫定値である。

団体名の照合で取り違えやすい組み合わせ（別団体なので注意）:

- 「ねぶた愛好会」（21番）と「東北電力ねぶた愛好会」（19番）
- 「JRねぶた実行プロジェクト」（13番）と「プロクレアねぶた実行プロジェクト」（23番）

来年版のPDFが届いたら、**番号を書き換える前にこのファイルを差し替える**こと。
`data/nebuta.json` は `node scripts/build-data.mjs` による生成物なので、
番号の変更はCSV側で行う。番号に重複や欠番があればビルドが失敗する。
