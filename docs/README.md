# docs

一次資料の置き場。**ここに置いたファイルは公開されない。**
GitHub Pages が配信するのは `npm run build` が生成する `out/` だけで、
`out/` に入るのは `app/` の出力と `public/` の中身に限られる。

## R8RasseLandMap.pdf

青森観光コンベンション協会「青森ねぶたラッセランド ねぶた制作小屋配置図」
（AOMORI NEBUTA FESTIVAL 2026）。

このアプリの**小屋番号（1〜23）の唯一の正**。`data/nebuta-source.csv` の
`Column 1` はこのPDFの番号に合わせてあり、一覧・詳細の「前へ／次へ」・
地図画面のリストはすべてこの番号順に並ぶ。

`lib/rasseland.ts` の相対座標も、このPDF右下の模式図を目視で採寸したもの。
**PDFに緯度経度の記載はない。**

`rassetLandCenter` の緯度経度は**PDFとは別の出典**による。2026-08-04に
青森観光コンベンション協会から回答を得て確定した（40.82962508 / 140.7418799、
青森県青森市安方2-1、出典: Amazing AOMORI 公式サイト）。**もう暫定値ではない。**
相対座標（`rassetLandHutPositions` ほか）は引き続きこのPDF由来であり、
緯度経度とは出典も精度も異なる。**両者を混同しないこと。**

団体名の照合で取り違えやすい組み合わせ（別団体なので注意）:

- 「ねぶた愛好会」（21番）と「東北電力ねぶた愛好会」（19番）
- 「JRねぶた実行プロジェクト」（13番）と「プロクレアねぶた実行プロジェクト」（23番）

## ui-text-review.md

留学生TAに渡すUI文言の翻訳確認シート。`lib/ui-text.ts` の37項目を
言語別（やさしい日本語／English／简体中文／繁體中文／한국어）の表に展開したもの。

**ねぶたの解説本文は含まない。** 解説本文・作品名・団体名・ねぶた師名・タグ値は
権利者から提供された確定テキストであり、翻訳・修正の対象外。

TAからの修正は `lib/ui-text.ts` 側に反映する。このファイルを直してもアプリには反映されない。
`lib/ui-text.ts` に項目を足したらこのシートも作り直すこと（表の No. は
末尾の付録で `lib/ui-text.ts` のキーに対応付けてある）。

来年版のPDFが届いたら、**番号を書き換える前にこのファイルを差し替える**こと。
`data/nebuta.json` は `node scripts/build-data.mjs` による生成物なので、
番号の変更はCSV側で行う。番号に重複や欠番があればビルドが失敗する。
